# samples

サンプル題材（台本・説明図の HTML・撮影用のローカルページ）を置きます。

- [`u-value/`](u-value/): 窓の断熱性能（U 値）の見方。説明図と、キットの中の計算ページの撮影の両方を見せる
- [`window-condensation/`](window-condensation/README.md): 冬の窓の結露のしくみと減らし方。一般の解説（`kind: explainer`）を、説明図の部品だけで作った例
- [`_parts/`](_parts/README.md): 解説の説明図の部品 7 種の見本

- [`_shared/diagram.css`](_shared/diagram.css): 説明図の共通の CSS（2420×1000、文字の大きさ・カードの並べ方）。書き方は [docs/design/diagram.md](../docs/design/diagram.md)
短い例の台本は [examples/](../examples/) にあります。
