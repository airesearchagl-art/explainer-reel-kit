# 数値・事実の根拠（冬の窓の結露のしくみと減らし方）

台本 [window-condensation.storyboard.md](window-condensation.storyboard.md) で使った数値・事実と、その根拠です。
台本を直したら、この一覧も一緒に直します。

## 使った数値

| 値 | 使った場所 | 根拠 |
|---|---|---|
| 20℃・湿度 60% の空気の露点は約 12℃ | s02 の説明図・ナレーション | [1]「結露が発生する温度と湿度の関係」 |

## 使った事実

| 事実 | 使った場所 | 根拠 |
|---|---|---|
| 暖かい空気ほど多くの水蒸気を含める。湿った空気が冷たい面で冷やされると、余った水蒸気が水滴になる | s01・s02 | [1]「結露とは」 |
| 結露が始まる温度を露点という | s02 | [1] |
| 結露は室内と室外の温度差（①）と、室内の湿度（②）で起きる。断熱サッシや複層ガラスでも結露することがある | s03 | [1] の冒頭 |
| 窓の表面温度が露点より下がると結露する。条件は室内の温度・湿度、外気温度、窓の断熱性能で決まる | s03（① の説明） | [2] |
| 洗濯物の室内干し・加湿器の使いすぎ・開けたままのお風呂のフタは、控えると水蒸気の発生を抑えられる（② のもと） | s04 | [1]「結露対策 2：水蒸気の発生を抑える」 |
| エアコン・電気ストーブ・密閉型の暖房機は水蒸気を出さない | s04・s05 | [1]「結露対策 2」 |
| ① 温度差への対策: 熱貫流率が小さい（断熱性の高い）窓ほど結露しにくい | s05 | [2] |
| ② 湿度への対策: 換気（調理中と後、入浴中と後、就寝前）、室内干しを控える、加湿器を使いすぎない | s05 | [1]「結露対策 1」「結露対策 2」 |

- s01 のたとえ（冷たい飲みものの缶）は、[1] のしくみ（湿った空気が冷たい面で冷やされて水滴になる）を身近な場面に当てはめたもので、数値は使っていません
- 条件（s03）と減らし方（s05）は ① 温度差・② 湿度 の同じ番号・同じ順・同じ色で対にしています（どちらか片方だけの項目はありません）
