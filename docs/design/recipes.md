# スライドとアニメーション（erkit deck）

`erkit deck <台本> --out <.pptx>` は、台本から 16:9・全スライド自動切替の .pptx を作ります。ナレーションの原稿は各スライドのノートに入ります。
コード: `src/explainer_reel_kit/deck/`。

```text
erkit deck examples/hello-kit.storyboard.md --out out/hello_kit.pptx \
  [--durations voice/durations.json] [--assets-root 画像のフォルダ] [--overlay out/overlay.png] [--credit 文言]
```

| 引数 | 内容 |
|---|---|
| `--durations` | ナレーションの段の `durations.json`。`items[].slide_sec` を id（`intro` / シーン id / `outro`）で対応させる |
| `--assets-root` | 画像の起点。既定は台本ファイルのフォルダ |
| `--overlay` | 確認用の一覧画像（各シーンの画像に、置いた赤枠・矢印を描いたもの） |
| `--credit` | 最後のスライドの左下に「ナレーション音声: <文言>」を出す（クレジットが必要な声のとき） |
| `--default-sec` | 秒数の決まらないスライドの秒数（既定 6） |

終了コード: 0 成功 / 1 作れない（台本の誤り・manual 画像の欠落・durations.json の形式違い） / 2 引数の誤り。

## スライドの構成

| スライド | 内容 | 動き |
|---|---|---|
| intro | 左に題名・要約・前提・所要時間、右に最初のシーンの画像の縮小（無ければ文字だけ） | 上から順にフェードイン |
| scene | 見出し、主画像（縦横比を保って収める。`zoom` なら注釈のまわりを拡大）、画面の文字、来歴ラベル（右下） | レシピのとおり |
| outro | 「まとめ」、要約、確認すること、次の行動、任意の画像 | 上から順にフェードイン |

- まだ無い画像（web / generated）は、灰色の枠に「撮影予定: <ref>」を出して作り続ける（プレースホルダー）。manual の画像が無いとエラー
- 秒数: `durations.json` の `slide_sec` ＞ 台本の `duration_sec` ＞ 既定 6 秒
- 文字が枠からはみ出す見込みなら、文字を縮める（最小 0.5 倍・10pt）。折り返しの見積もりは行頭禁則を考え、PowerPoint にも日本語の改行規則を使わせる
- イントロの「所要時間」: 台本の `duration_note` に値があればそれ。「未計測」・空なら、`--durations` があるときだけ動画の長さ（約 1 分 28 秒の形）
- `recipe_params.card: {title, text, meta}` があるシーンは、画像の代わりに文字だけのカードを描く（プレースホルダーには数えない）

## レシピ（recipe）と recipe_params

座標はすべて**主画像に対する 0〜1 の相対座標**（左上が 0, 0）。形式に合わない値はエラーにせず既定値を使い、警告を出す。未知のキーは無視する。効果はすべて「前の動作の後」で連鎖し、開始の遅れと長さを明示する（クリック進行は使わない）。

| recipe | recipe_params | 動き |
|---|---|---|
| `fade_sequence` | なし | 見出し → 画像 → 画面の文字の順にフェードイン |
| `highlight_box` | `mark: 名前` か `mark: [名前, …]`、任意で `pad`（画像幅に対する比、既定 0.01）、`zoom`。座標で書くなら `box: {x, y, w, h}` | 赤枠（4.5pt）がフェードイン → 点滅 1 回。複数なら前の枠を消してから次の枠 |
| `arrow_move` | `to: {mark: 名前}`、任意で `from_side`（left / right / top / bottom、既定 left）、`from: {x, y}`、`zoom` | 赤い矢印が `from` から動き、先端が部品の枠の外側の辺で止まる |
| `text_build` | `lines: [文字列, …]`（任意。既定は画面の文字を改行で分けたもの） | 見出し → 画像の後、文字を段落ごとに順にフェードイン |
| `morph_transition` | なし | 前のスライドから変形（Morph）でつなぐ |

```yaml
recipe: highlight_box
recipe_params:
  mark: [input_area, result_area]   # 2 つの枠を順に出す
  zoom: per_mark                    # 枠ごとにスライドを分け、Morph でカメラが動くようにつなぐ
```

### 拡大（zoom）

**Web の画面は拡大して見せる**: 撮影の既定（1600×660 ×1.5 倍、画像枠と同じ縦横比）なら拡大しなくても読める。1920×1080 で撮った画面（16:9 は枠に縦で合わせて縮み、文字が約 0.68 倍になる）や、小さな部品を見せるシーンには `zoom` を付ける（[capture-web.md](capture-web.md#画面の大きさ--動画で文字が読めるように)）。

- `zoom: true`（または `{margin: 0.1}`）: シーンの注釈すべてを囲む範囲（余白は画像幅の 8%）を、画像枠と同じ縦横比で切り出して拡大する。元画像からはみ出さず、切り出す幅は元画像の 40% 以上（最大 2.5 倍）。画像は元のまま入れ、PowerPoint の切り抜きで見せる（PowerPoint で戻せる）
- 縦に長い部品は、注釈の範囲の縦横比のまま切り出し、画像枠を細くして中央に置く。通常の切り出しの拡大率が 1.5 倍未満で、細い枠の方が大きく見えるときも細い枠にする
- `zoom: per_mark`（`highlight_box`、枠が 2 つ以上）: 枠の数だけスライドに分け、各スライドをその枠を中心に拡大し、Morph でつなぐ。2 枚目以降への変形は、ナレーションの段落の開始時刻に始まる。ナレーションは最初のスライドのノートに入る
- 位置の決まらない注釈があるシーン・画像がまだ無いシーンは拡大しない（警告）

### 時刻

| 項目 | 値（ms） |
|---|---|
| スライド表示から最初の効果まで | 300 |
| 文字のフェード / 画像のフェード | 500 / 700 |
| 段と段の間 | 150 |
| 赤枠のフェード / 点滅 | 400 / 600 |
| 矢印のフェード / 移動 | 300 / 1200 |

- 複数の枠は、`durations.json` の `items[].paragraph_starts_sec`（ナレーションの段落ごとの開始秒）が枠の数と同じならそれに合わせる。違う・無いときは残り時間を均等に割り、警告する
- アニメーションの合計がスライドの秒数を超えるときは、同じ比率で縮めて警告する

## 注釈の位置（marks）

赤枠・矢印の位置は、**撮影や説明図を描くときに測る**。台本には座標を書かず、どの部品を指すかを名前（mark、英小文字・数字・`_`）で書く。

撮影・説明図の段は、画像と同じフォルダに `<画像名から拡張子を除いたもの>.marks.json` を置く。

```json
{
  "format": "explainer-reel/marks@1",
  "scene": "s01",
  "source": "web",
  "image": "s01.png",
  "image_size": {"w": 1920, "h": 1080},
  "captured_at": "2026-11-06T10:00:00+09:00",
  "marks": {
    "input_area": {"box": {"x": 0.12, "y": 0.18, "w": 0.16, "h": 0.22}, "px": {"x": 230, "y": 194, "w": 307, "h": 238}, "how": "selector: ..."}
  }
}
```

- `box` は画像に対する 0〜1、`px` は画像のピクセル。点を指すときも小さな `box` で書く
- 測る側の責任: 見つからない・非表示・8px 未満・画像からはみ出す部品は記録せず、理由を残す
- **位置の決まらない注釈**（記録ファイルが無い・名前が無い・mark も座標も無い）は、件数とシーンを表示し、既定の位置（中央 50%、左 → 右）に置く。通し生成では止める
- 確認用の一覧画像（`--overlay`）: 確定した注釈を赤、未確定を橙で描き、複数の枠には番号を付ける

## 実装の決まり

- python-pptx にアニメーションの API が無いため、`p:timing` と `p:transition` を XML で直接書く（`timing.py`）
- PowerPoint の拡張（`mc:AlternateContent`）は Morph の切替にだけ使う（Choice = `p159:morph option="byObject"`、`p14:dur` 1000ms、Fallback = 同じ `advTm` のフェード）。Windows で、修復なしで開け、動画でも変形することを確かめた形
- 変形は自動切替のタイマーの前に再生される（動画の長さ ＝ advTm ＋ 変形の長さ）
- スライドには `er:<シーン id>`（分けたものは `er:<id>#<n>`）の名前を付ける。音声の合成はこの名前でスライドをシーンにまとめる
- 動きの確認は PowerPoint（Windows）で行う
