# 2. 見る人（audience）

台本の `audience` に、見る人の種類を書きます。言葉の選び方・説明の深さ・前提の書き方が変わります。

| 値 | 見る人 | 言葉 | 深さ | 前提（intro の `prerequisites`） |
|---|---|---|---|---|
| `A` | 初めての人 | 専門用語は最初に一言で言い換える。1 シーンに新しい言葉は 1 つまで | 「何のためか」「何が分かるか」を先に。仕組みの細部は省く | 書かなくてよい（ブラウザがあれば、など最小限） |
| `B` | よく使う人・詳しい人 | 分野の言葉はそのまま使ってよい | 手順と判断の分かれ目を中心に。設定の意味も触れる | 使うツール・版を書く |
| `C` | 専門家・作る人 | 正確な用語・単位・条件 | 仕組み・制約・例外まで。数値の条件と根拠を明示する | 必ず書く（環境・版・前提の知識） |

## 決め方

- 「見る人がいちばん知らない人」に合わせます（混ざっていれば低い方）
- 迷ったら A にして、詳しい人向けの補足は outro の `checks` や `next` に回します

## ナレーションの書き分けの例（サンプルの s02 を見る人ごとに）

| 値 | 例 |
|---|---|
| A | ユー値は、ガラス一平方メートルあたり、室内と室外の温度差が一度のときに、何ワットの熱が流れるかを表す数字です。小さいほど、熱を通しにくい窓になります。 |
| B | ユー値、熱貫流率は、面積一平方メートル・温度差一度あたりの熱の流れです。カタログの値がガラスだけか、枠を含む窓全体かを確かめて比べます。 |
| C | ここで扱うのはガラス中央部の熱貫流率で、単位はワット毎平方メートル毎ケルビンです。中空層の厚さとガスの有無で変わるため、規格の区分の範囲で示します。 |

## AI に任せること

- 聞き取りの答え（見る人・もう知っていること）から A・B・C を提案し、理由を一言添えて人に確かめる
- チャットだけの AI: [prompts/01-intake.md](../../prompts/01-intake.md) の最後で提案させる
