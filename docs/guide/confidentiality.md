# 社外秘の区分と AI の使い分け

## 最初に決める

**最初に、この動画の材料に社外秘（所属先の外に出せない情報）が含まれるかを決めて、台本の `confidentiality` に書きます。分からなければ `confidential` です。**

| 区分 | 材料 | 対話・台本づくりに使う AI |
|---|---|---|
| `general` | 公開済みの情報・一般的な知識だけ | クラウドの AI を使ってかまいません。品質の高い AI を選ぶのがおすすめです |
| `confidential` | 社外秘を含む・分からない | **この PC の中で動く AI**（LM Studio・Ollama など）か、所属先が社外秘の扱いを認めている AI だけ |

- 台本に書いていなければ、キットは `confidential` として扱います（`General` のような書き間違いも `confidential`）
- どの AI を使ってよいか、何が社外秘に当たるかは、**所属先のルールに従ってください**。このキットはその判断をしません

## キットが止めるもの・止められないもの

| | `confidential` のときの動き |
|---|---|
| 撮影（`erkit capture`・`erkit make`） | この PC の中の URL（`127.0.0.1`・`localhost`・`file://`）しか撮りません。外の URL があれば、ブラウザを開く前に止まります |
| 説明図（`erkit diagram`） | いつもネットワークを止めて描きます（区分によらず） |
| ナレーション（`erkit voice`・`erkit make`） | 音声合成エンジンの URL がこの PC でなければ、原稿を送らずに止まります |
| 通し生成（`erkit make`） | 始める前に上の設定をまとめて確かめ、外へ出る設定があれば何も作らずに止まります（`--dry-run` でも確かめる） |
| **対話に使う AI** | **キットでは止められません**。人とエージェントが守ります |

区分によらず、外へ出る設定を許さずに作りたいときは `--offline` を付けます（`erkit make samples\u-value\u-value.storyboard.md --serve samples\u-value\app --offline`）。

## エージェントとの約束

`AGENTS.md` に書いてあり、エージェントはこれに従います。

- 区分が決まる前に、資料を読まない・どこにも送らない
- `confidential` のとき、エージェントがクラウドで動いているなら、**資料を受け取らずに止まり**、この PC の中で動く AI で進めるよう人に伝える
- 区分を `confidential` から `general` に変えるのは人だけ（エージェントは下げない。上げるのはよい）

## 社外秘の材料で進めるには

1. この PC で LLM を動かす（LM Studio・Ollama など）。手元の LLM のチャット画面に [prompts/](../../prompts/README.md) を貼って進めます
2. 撮るページはこの PC で動かす（`--serve` か、この PC で起動したアプリ）。社外秘の画面の操作定義は記録モード（`erkit record`）で作ると、AI に画面を見せずに済みます
3. 音声合成エンジン（AivisSpeech）はこの PC で動かす（既定のまま）
4. 台本・撮影画像・出力をキットのリポジトリに commit しない。共有するときは所属先のルールで

手元の AI は、クラウドの AI より説明が淡々としやすく、人が直す量が増えます。下書きとして扱い、必ず人が直してください。
