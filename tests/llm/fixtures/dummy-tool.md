# かんたん集計ページ（テスト用のダミーの資料）

このファイルは erkit draft のテストと試しの実行に使う、架空のツールの説明です。実在のツールではありません。

## できること

- 表の CSV ファイルを読み込み、列ごとの合計と平均を表示します
- 読み込める行数は 1 ファイルあたり 5000 行までです
- 結果は画面の右側に表で出ます。「書き出す」ボタンで CSV に保存できます

## 使い方

1. ブラウザでページを開きます
2. 左の「ファイルを選ぶ」から CSV を選びます
3. 集計したい列にチェックを入れます
4. 「集計する」ボタンを押すと、右側に合計と平均が出ます
5. 必要なら「書き出す」ボタンで結果を保存します

## 注意

- 文字コードは UTF-8 だけです
- 数値でない値の入った行は、集計から外して件数を表示します
- ページはこの PC の中だけで動き、ファイルをどこにも送りません
